# 자주 묻는 질문

## Markdown을 알아야 하나요?

아니다. 프로젝트에 접근할 수 있는 AI에게 적용 요청을 하면 된다. AI가 조사하고 지침 파일을 작성한다. 사용자는 프로젝트 위치와 원하는 결과를 알려 준다.

## 사람이 만든 코드에도 쓸 수 있나요?

그렇다. 누가 코드를 작성했는지보다 기존 동작·소비자·데이터를 확인하는 것이 중요하다. 문서나 테스트가 부족하면 변경하는 기능부터 조사와 검증 기준을 마련한다.

## 어떤 언어를 지원하나요?

규칙은 특정 언어에 종속되지 않는다. 언어별 실행·검사 명령과 모듈 구조는 AI가 실제 프로젝트에서 확인한다. 모든 언어에 대한 실행 도구를 제공하는 패키지는 아니다.

## 신규 개발도 가능한가요?

구조 원칙은 활용할 수 있다. 현재 안내의 중심은 기존 프로젝트 유지보수·리팩토링이다. 아이디어·화면 기획·첫 구현을 모두 이끄는 신규 개발 모드는 향후 범위다.

## 주소만 알려 주면 영구 적용되나요?

주소는 원본 위치다. AI가 읽고 실제 프로젝트에 파일을 적용해야 한다. 한 번 적용하면 프로젝트 파일이 작업 기준이 된다. 도구의 로딩과 실제 경로는 새 세션에서 확인한다.

## 기존 CLAUDE.md나 AGENTS.md가 있으면요?

AI가 비교해 병합한다. 기존 프로젝트 정책과 사용자 변경을 덮어쓰지 않는다. 설치 요청만으로 운영 배포나 제품 코드 개편을 진행하지 않는다.

## 공개 저장소가 업데이트되면 자동 반영되나요?

자동 반영되지 않는다. 적용한 버전과 원본을 기록하고 업데이트 요청 시 차이를 비교해 병합한다. 프로젝트 설정과 계약은 보존한다.

## 안전한 유지보수를 보장하나요?

작업 기준을 제공한다. 실제 테스트·CI·DB 권한·리뷰와 함께 사용해야 한다. 모듈 교체는 계약·데이터 호환성·검증·복구 준비가 확인돼야 한다.

## MIT로 공개하면 상업적 이용도 가능한가요?

저작권·라이선스 고지를 보존하는 조건으로 사용·수정·재배포·상업적 이용을 허용한다. 원문은 [LICENSE](../LICENSE)를 참고한다. 적용 프로젝트 자체를 MIT로 바꾸는 요구는 없다.

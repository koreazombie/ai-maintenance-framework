# AI Maintenance Framework v0.1.0

기존 프로젝트의 AI 유지보수·리팩토링을 위한 한국어 작업 지침입니다.
Claude Code/Codex 진입점, 공통 규칙, AI 적용 절차, 프로젝트·모듈·계약 양식,
검증 체크리스트와 가상 TypeScript/PostgreSQL 예시를 제공합니다.

기본 정책은 PATCH 우선과 실용형 절차입니다. MIT 라이선스로 배포합니다.

## 시작 방법

README의 적용 요청문을 프로젝트에 접근할 수 있는 AI에게 전달하세요.
기술 설정은 AI가 조사하며, 사용자는 프로젝트 위치와 원하는 변경을 알려 줍니다.

## 검증

- 로컬 문서·참조·메타데이터 검사 통과.
- 검사 도구의 정상/오류 시나리오 테스트 6개 통과.
- 실제 제품 적용과 AI 도구 세션 실행은 검증 범위 밖입니다.
- GitHub Package checks의 결과는 저장소 Actions에서 확인하세요.

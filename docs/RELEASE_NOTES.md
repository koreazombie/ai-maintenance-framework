# AI Maintenance Framework v0.2.0

설치되는 파일을 **CLAUDE.md + AGENTS.md + `.ai/` 한 폴더**로 정리했습니다.
규칙·모듈 계약·양식·검증 기준·작업 기록·사용 안내·예시·라이선스는 `.ai/` 안에서 관리합니다.

설치할 때 지침을 공개 코드와 함께 관리할지, 로컬 또는 별도 비공개로 관리할지 확인합니다.
비공개 설정의 실제 Git 추적·ignore·스테이징 확인과 다른 환경 재설치 조건을 포함합니다.

## 기존 사용자

v0.1.0에서 생성한 파일은 자동 이동하지 않습니다.
프로젝트 AI에게 v0.2.0으로 이전을 요청하면 docs/MIGRATING-0.2.md에 따라
기존 설정·계약·사용자 파일을 보존하며 경로를 정리하도록 안내합니다.
실제 제품 코드·실행 테스트·API 스키마는 기존 위치를 유지합니다.
이미 공개된 과거 커밋은 이번 구조 변경만으로 삭제되지 않습니다.

PATCH 우선/실용형 정책과 MIT 라이선스는 유지합니다.
검증은 배포 구성과 검사 도구에 대한 것이며 실제 사용자 프로젝트의 동작·도구 세션을 보장하지 않습니다.

# v0.3.0 검증 기록

날짜: 2026-10-12. 배포/설치 검증 테스트 29개와 단일 스크립트 테스트 2개 통과. 로컬 검사 완료. 이 배포 커밋의 GitHub 검사 결과는 릴리스에 기록한다.

- 배포 문서·링크·가져오기·필수 파일·라이선스·메타데이터 검사.
- 프로파일 catalog가 실제 원본 규칙/검사기 해시와 일치하는지 검사.
- solo/modular 설치 fixture에서 실제 기록·설치 검증.
- 솔로의 지침 Markdown이 세 개뿐이고 모듈형 폴더가 없는지 확인.
- placeholder, 파일 누락·변경, 버전/프로파일 불일치, 잘못된 메타데이터·인코딩과 경로 탈출 실패 사례 확인.
- 실제 임시 Git 저장소에서 local-all 제외, 이미 추적된 비공개 진입점, 누락 ignore와 잘못 숨겨진 공유 파일 검사.
- 설치된 검사 CLI의 자동 프로젝트 경로와 성공/실패 종료 코드 확인.
- 단일 스크립트 예시의 실제 계산·빈 입력·입력 보존 테스트.

설치 fixture는 격리된 테스트 프로젝트다. 실제 사용자의 기존 프로젝트를 설치·이전한 결과나 AI 세션 로딩 검증은 아니다. 검사기는 산문의 진실·제품의 업무 정합성·과거 공개 Git 이력 삭제를 확인하지 않는다.

임의로 원본 catalog와 검사기까지 함께 바꾸는 공격을 막는 서명 체계는 아니다. 원본 버전과 해시를 확인해 실수·누락·기록 이후 변경을 탐지하는 도구다.

# 프로젝트 적용 안내

실제 설치·이전은 원본 저장소의 INSTALL.md를 읽고 진행한다. 설치 범위는 두 루트 진입점과 `.ai/`다.

1. 프로젝트와 기존 지침·Git 상태를 조사한다.
2. `.ai/`의 함께 관리/로컬 비공개/비공개 별도 관리 중 사용자의 선택을 확인한다.
3. 같은 이름의 기존 내용을 보존·병합하고 `.ai/PROJECT.md`를 실제 설정으로 채운다.
4. `.ai/PRIVACY.md`와 `.ai/FRAMEWORK.md`에 관리 방식·버전·원본·동기화 방법을 기록한다.
5. 진입점 경로·가져오기, Git 추적·스테이징·ignore와 기존 파일 보존을 검증한다.
6. 새 AI 세션의 실제 지침 로딩을 확인하고 결과를 보고한다.

기존 버전은 원본 저장소 docs/MIGRATING-0.2.md에 따라 프레임워크 문서만 옮긴다. 기존 제품 문서·실행 테스트·API 스키마는 유지한다. 이미 공개된 Git 이력은 폴더 이동이나 ignore로 제거되지 않는다.

작은 변경부터 적용하고 `.ai/modules/<module>/`에 필요한 행동 계약과 설명을 정리한다. `.ai/templates/`의 양식을 사용한다. 필요한 실제 검사 장치는 [검증 연결 안내](../verification/GATES.md)를 참고한다.

비공개 폴더가 새 환경에 없으면 해당 환경의 설치·동기화 필요를 알린다. 확인되지 않은 로딩과 미실행 제품 검증을 완료로 표시하지 않는다.

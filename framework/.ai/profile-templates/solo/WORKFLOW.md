# 작업 흐름 — 스크립트/솔로

1. PROJECT.md와 관련 코드·설정·기존 검사를 읽는다.
2. 요청의 기대 동작을 정하고 모호한 업무 결정만 묻는다.
3. 작은 변경은 바로 수정하고, 범위가 크면 짧게 계획을 공유한다.
4. 필요한 실행·회귀 검증을 수행한다. 입력·출력·오류와 사용자 변경 보존을 확인한다.
5. 변경한 내용, 실제 검사 결과와 남은 제약을 쉽게 보고한다.

'검토해 줘'면 확인한 문제와 범위를 정리하고, '리팩토링해 줘'면 기존 동작을 보존하며 필요한 변경과 검증을 진행한다. 검토 전용 요청을 구현 허가로 확대하지 않는다.

'테스트/CI 설정해 줘'면 기존 검사·런타임·저장소 도구를 조사하고, 핵심 동작 검사를 마련해 로컬에서 실행한 뒤 사용하는 CI에 연결한다. 실제 CI 실행과 필수 병합 조건은 권한 범위 안에서 확인하며 미실행·미설정은 구분한다. CI는 비공개 `.ai/`에 의존하지 않게 한다.

지침을 변경하면 `.ai/tools/validate_installation.py`로 버전·파일·설정·Git 상태를 확인한다. 의도적으로 수정한 사용자 설정은 내용을 검토한 뒤 원본 저장소의 record_installation.py로 검증 기준을 갱신한다. 실패를 숨기려고 기준을 무조건 갱신하지 않는다.

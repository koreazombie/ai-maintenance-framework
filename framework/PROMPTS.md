# 복사해서 쓰는 시작 프롬프트

일반 대화 요청용이다. 전용 slash command나 자동 실행 기능을 설치하지 않는다.

## 프로젝트 초기 점검

이 프로젝트에 적용되는 CLAUDE.md 또는 AGENTS.md와 공통 규칙을 읽고 현재 구조를 조사해 줘. 아직 구현은 바꾸지 말고 `.ai/PROJECT.md`를 실제 설정으로 채워 줘. 모듈 책임·공개 진입점·데이터 소유권·실제 검증 명령을 확인하고, 확인된 사실과 추정·미확인 항목을 구분해 줘. 운영 데이터에는 쓰지 마. 필요한 핵심 질문만 해 줘.

## 기능 변경

<기능>을 구현해 줘. 목표는 <수용 기준>이고 <비범위>는 제외해. 적용 지침과 관련 계약·소비자·테스트를 확인하고 PATCH 우선으로 진행해 줘. 위험도에 맞는 검증을 실행하고, 행동이 바뀌면 계약도 갱신해 줘. 결과와 실제 검증·미실행 항목·남은 위험을 알려 줘.

## 버그 수정

<현상>을 재현하고 <기대 행동>의 근거를 확인해 줘. 관련 불변조건과 소비자 영향을 조사한 뒤 최소 PATCH로 고쳐 줘. 필요한 회귀 검증을 추가하거나 실행하고 실패를 감추려고 기대값을 바꾸지 마. 재현/수정 결과와 남은 제약을 알려 줘.

## REBUILD 검토

<모듈>을 재생성할 가치가 있는지 PATCH와 비교해 줘. 계약·데이터 소유권·외부 부작용·독립 검증·복구 준비 상태를 조사하고, 부족한 준비를 진행해 줘. 기존 계약과 영속 데이터를 보존하는 교체 계획을 파일로 남겨 줘. 이 요청의 범위는 조사·계약화·검증 준비와 로컬 교체까지이며 운영 적용은 제외야.

## 구현과 별도의 검증 관점 리뷰

이 diff를 요구사항·계약·불변조건을 기준으로 검토해 줘. 특히 테스트 정답이 새 구현에 종속됐는지, 기대값·게이트가 약화됐는지, 데이터·권한·동시성·소비자 호환성이 깨졌는지 확인해 줘. 문제는 위치·재현 조건·영향·근거를 적고, 실행하지 못한 검사는 따로 알려 줘.
